# Vite & Gourmand

## Lancement local

1. Installer Docker Desktop et le démarrer.
2. Cloner ce dépôt.
3. Copier `.env.example` vers `.env`.
4. Lancer `docker compose up --build`.
5. Ouvrir http://localhost:8080
6. Ouvrir http://localhost:8025 pour lire les mails.

Le premier démarrage prend plusieurs minutes.
