VITE ET GOURMAND 

« Vite & Gourmand » est une entreprise constituée de deux personnes, Julie et José. Elle existe depuis 25 ans à Bordeaux, et propose leurs prestations pour tout événement.

Le but de l’application est de pouvoir montrer le menu aux visiteurs ainsi que permettre la
commande.

Lien Trello : https://trello.com/b/6aed087b01e731d85fcc1ae6

## Installation

### Prérequis
- XAMPP installé dans C:\Env\xamp. Démarrer Apache et MySQL.
- PHP 8.2, Composer, MariaDB
- MongoDB Atlas : la chaîne de connexion se place dans un fichier .env (ne pas la mettre sur GitHub)
- Mailpit : lancer mailpit.exe, puis ouvrir http://127.0.0.1:8025

### Lancer le projet
Dans le dossier du projet : php -S localhost:8000
(le site sera disponible à partir du ticket VG-07)
